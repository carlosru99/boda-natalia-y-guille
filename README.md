## 🚨 Descripción de la incidencia

Queridos Natalia y Guille:

Tenemos un problema en producción.

El sistema que gestiona vuestra boda salió a producción un viernes por la tarde, sin pasar QA y con el Account Manager
diciendo que "era un cambio pequeñito". Ya os imagináis lo que pasó.

Ahora mismo:

- El Excel de invitados tiene más duplicados que un informe de horas a final de mes.
- El buscador de vuelos de la luna de miel no se ha leído el acuerdo de Alianzas.
- Las dos familias, la de Daimiel y la de Brasil, comparten mesa y no hay traductor.
- Los gatos exigen sus premios y no están para bromas.
- El cura no sabe validar un "sí quiero".
- Y un módulo legacy dice que no sois compatibles. 🙄

Hay un **sobre** que no se puede abrir hasta que todo esté en verde.

## 🛠️ Cómo arrancar

```bash
python3 boda.py
```

No hay que instalar nada: es Python a pelo. Al ejecutarlo veréis 6 tests en rojo. Vuestra misión es dejarlos en verde.

## 📋 Reglas del sprint

1. Solo se toca la **ZONA DE TRABAJO** de `boda.py`. Los tests están validados por el cliente.
2. Sin internet, sin IA y sin llamar a nadie del equipo. Solo vosotros dos.
3. Se trabaja **en pareja**. Esto es pair programming de verdad.
4. El sobre **no se abre** hasta que el programa os lo diga.
5. Estas horas no se imputan.

## ✅ Definition of Done

```
6/6 tests en verde.
```

Si llegáis hasta ahí, el sistema tiene algo que deciros. 💌
